GUÍA ARQUITECTÓNICA: DESPLIEGUE Y MANTENIMIENTO DE CONSTRUFACIL
=============================================================================

1. EL PROBLEMA DE SUPABASE (El "Coma Inducido")
-----------------------------------------------------------------------------
La Regla del Juego: En su plan gratuito, Supabase apaga tu base de datos si
no detecta actividad (lecturas o escrituras) durante 7 días seguidos. Si un
reclutador entra a tu app el día 8, la pantalla estará en blanco y la base
de datos tardará 3 minutos en "despertar" (Cold-Start).

La Solución Definitiva: Necesitas automatizar un "latido del corazón" (Heartbeat).
La forma más profesional de hacerlo es configurar un Cron Job (una tarea
programada) que haga una consulta básica a tu base de datos frecuentemente.

- El Hack Automático: Si tu scraper envía datos nuevos a Supabase un par de
  veces por semana, ese mismo guardado de datos cuenta como actividad. Mientras
  el scraper funcione, Supabase nunca se dormirá.
- El Plan B (cron-job.org): Si no vas a correr el scraper automáticamente,
  puedes crear una cuenta gratuita en cron-job.org y configurarlo para que
  haga una petición HTTP a tu base de datos de Supabase cada 3 días. Esto
  engaña al sistema haciéndole creer que hay usuarios activos.


2. EL ALOJAMIENTO DEL BACKEND (GitHub Actions)
-----------------------------------------------------------------------------
El error de novato: Subir un scraper con Playwright a servidores gratuitos
como Render o Railway. Abrir navegadores Chromium consume muchísima memoria RAM.
Los servidores gratuitos cortarán el proceso por falta de memoria (OOM - Out
of Memory) y tu bot morirá a la mitad.

La Arquitectura Nivel Semi-Senior: Usaremos GitHub Actions.
GitHub Actions no es un servidor 24/7, es una herramienta de automatización
que te presta un computador potente de forma gratuita por unos minutos al día.

¿Cómo funcionará este flujo en tu portafolio?
1. Crearemos un archivo `.yml` dentro de tu repositorio de GitHub.
2. Le diremos a GitHub: "Todos los días a las 04:00 AM, prende un servidor Ubuntu".
3. "Instala Node.js, instala Playwright, y ejecuta mi archivo dataMiner.js".
4. Tu bot recorrerá Sodimac, Easy e Imperial a máxima velocidad usando el internet
   gigabit de los servidores de Microsoft/GitHub.
5. Tu bot tomará el JSON final y hará un "upsert" (actualizar/insertar) directo
   en tu base de datos de Supabase.
6. GitHub apaga el servidor.

¿Por qué esto destaca en una entrevista?
Pasas de decir "Tengo un script local" a decir "Configuré un pipeline de CI/CD en
GitHub Actions que orquesta un Web Scraper asíncrono todas las madrugadas, limpia la
data y alimenta mi base de datos en Supabase para evitar el Cold-Start del Tier Gratuito".
Eso demuestra mentalidad de ingeniero de software profesional.
